# Coffee Shop Full-Stack Application

This repository contains the Coffee Shop full-stack application. It has been restructured from a static website into a production-ready client/server layout.

## Project Structure

```
Coffee-Shop/
├── client/              # Frontend web application
│   ├── assets/          # Static assets (images, icons, fonts)
│   ├── css/             # Stylesheets (style.css)
│   ├── js/              # Client-side JavaScript (main.js)
│   ├── pages/           # Client-side pages/routes
│   ├── index.html       # Main HTML entry point
│   └── README.md        # Original frontend README
│
├── server/              # Backend server application (empty placeholder)
│
├── .gitignore           # Git ignore configuration
├── LICENSE              # License file
└── README.md            # Root project README (this file)
```

## Getting Started

### Client (Frontend)

To run the frontend locally:
1. Navigate to the `client/` directory.
2. Open `index.html` in your web browser, or use a live server extension (like VS Code Live Server).

### Server (Backend)

The server component is currently a placeholder for future backend development.
